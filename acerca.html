Acerca de NUBEX

NUBEX es un servicio de almacenamiento en la nube pensado para guardar, ordenar y compartir tus archivos desde cualquier lugar. Este sitio fue desarrollado como trabajo práctico de la materia Modelos y Sistemas, a partir de un boceto de diseño (wireframe) y un Diagrama de Flujo de Datos (DFD).

El sitio está construido con HTML, CSS y JavaScript básicos, usando el almacenamiento local del navegador (localStorage) para simular una base de datos con las cuentas de usuario, los archivos subidos y las suscripciones compradas.

Los planes disponibles son: Gratuito (500 GB, con anuncios), Normal (1 TB, sin anuncios) y Premium (espacio ilimitado, soporte prioritario).
